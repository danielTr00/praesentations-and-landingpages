## 1. EXECUTIVE SUMMARY

Diese Research-Analyse untersucht die drei Top-Konkurrenten (Stripe Atlas, Firstbase, Doola) sowie führende Finanzdienstleister und Rechtsberatungspages aus zwei Perspektiven: **SEO/Content** und **visuelles Design**. ## 5. TECHNICAL SEO: BEST PRACTICES FÜR LANDING PAGES

### 5.1 Core Web Vitals als Ranking-Faktor

| Metric | Ziel-Wert | Messung | Optimierung |
|---|---|---|---|
| **LCP (Largest Contentful Paint)** | < 1.2s | PageSpeed Insights | Inline critical CSS, preload hero image |
| **FID/INP (Interactivity)** | < 80ms | Web Vitals API | Minimal JS, lazy loading non-critical |
| **CLS (Cumulative Layout Shift)** | < 0.05 | Layout Shift API | Fixed aspect ratios für alle Elemente |

### 5.2 Mobile-First SEO Checklist

```markdown
[X] Viewport Meta Tag: "width=device-width, initial-scale=1.0"
[ ] Responsive Images mit srcset und sizes Attributen
[ ] Touch Targets mindestens 48x48px (WCAG 2.1)
[ ] Font Size mindestens 16px für Fließtext
[ ] Mobile-freundliche Navigation (Hamburger Menu)
[ ] Page Speed Mobile Score > 90/100
[ ] AMP? Nein (kein AMP nötig bei guter Performance)
```

### 5.3 Technical SEO Deep Dive

#### Schema.org Markup (muss auf CLG Landing Page):

| Schema Type | Zweck | Implementierung |
|---|---|---|
| **FAQPage** | Rich Snippets in Google für FAQ-Fragen | JSON-LD im `<head>` |
| **LegalService** | Local SEO für Finanzberatung | JSON-LD mit Kontakt-Infos |
| **Organization** | Knowledge Panel Potenzial | JSON-LD mit Logo/URL |
| **BreadcrumbList** | Enhanced SERP Darstellung | JSON-LD in allen Pages |
| **WebSite** | Site Search Integration | JSON-LD mit Search Action |

#### OpenGraph / Twitter Card (Social SEO):

```json
{
  "og:title": "Vermögensschutz durch UK CLG | DACH-kompatibel",
  "og:description": "Rechtssichere Vermögensstruktur für DACH-Mandanten. Jetzt Erstberatung anfragen.",
  "og:image": "https://clg-protect.de/static/og-image.jpg",
  "og:image:width": "1200",
  "og:image:height": "630",
  "og:url": "https://clg-protect.de/",
  "og:type": "website",
  "twitter:card": "summary_large_image",
  "twitter:title": "Vermögensschutz durch UK CLG",
  "twitter:description": "Rechtssichere Vermögensstruktur für DACH-Mandanten.",
  "twitter:image": "https://clg-protect.de/static/og-image.jpg"
}
```

### 5.4 Performance-SEO: Die wichtigsten Techniken

1. **Critical CSS Inlining** — Erstes Rendern ohne blockierende Stylesheets
2. **Preconnect zu externen Quellen** — Fonts, Analytics (wenn verwendet)
3. **Defer Non-Critical JS** — Kontaktformular und FAQ bleiben interaktiv
4. **Lazy Loading ab 2. Screenfold** — Above-the-fold sofort sichtbar
5. **HTTP/2 Server Push für Critical Assets** — Nginx Server-Push Header
6. **Brotli Compression aktivieren** — 15-20% besser als Gzip
7. **Static Asset Caching (90 Tage)** — Für alle CSS/JS/Images

## 9. PERFORMANCE-OPTIMIERUNG: CORE WEB VITALS STRATEGIE

### 9.1 Performance-Ziele für CLG Landing Page

| Metrik | Ziel-Wert | Messmethode | Optimierungs-Maßnahme |
|---|---|---|---|
| **LCP** | < 1.2s (Mobile) | PageSpeed Insights | Inline critical CSS, preload hero img |
| **FID/INP** | < 80ms | Web Vitals API | Minimal JS, passive event listeners |
| **CLS** | < 0.05 | Layout Shift API | Fixed height für alle Medien |
| **Total Page Size** | < 80 KB | Network Panel | Brotli komprimieren, minimal CSS |
| **TTFB (Server)** | < 200ms | Nginx Access Log | FastAPI + SQLite WAL + Redis Cache |

### 9.2 Technische Optimierungen pro Schicht

#### Nginx Layer:
```nginx
# Brotli Compression aktivieren
brotli on;
brotli_comp_level 6;
brotli_types text/plain text/css application/json application/javascript text/xml;

# HTTP/2 erzwingen
http2 on;

# Caching für Static Assets (90 Tage)
location ~* \.(css|js|png|jpg|jpeg|gif|svg|ico|woff2)$ {
    expires 90d;
    add_header Cache-Control "public, immutable";
}

# Security Headers
add_header X-Frame-Options DENY;
add_header X-Content-Type-Options nosniff;
add_header X-XSS-Protection "1; mode=block";
add_header Referrer-Policy "strict-origin-when-cross-origin";
```

#### FastAPI Layer:
```python
# GZip Response Middleware für nicht-static Assets
from fastapi.middleware.gzip import GZipMiddleware
app.add_middleware(GZipMiddleware, minimum_size=1000)

# CORS nur für erlaubte Domains
allow_origins=settings.allowed_origins_list

# Rate Limiting (Redis-basiert)
# 10 Requests/min pro IP auf /api/leads/submit
# 5 Requests/min pro IP auf /admin/
```

#### Frontend Layer:
```html
<!-- Preload Critical CSS -->
<link rel="preload" href="/static/css/main.css" as="style">

<!-- Preconnect zu Fonts -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

<!-- Defer Non-Critical JS -->
<script src="/static/js/contact.js" defer></script>
```
